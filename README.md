Herramientas de Gestión de Actividades (PAIT)

Durante esta semana apliqué una herramienta de gestión de actividades para organizar las tareas del proyecto *Store-Web*.  
Usé *Trello* para planificar y controlar los avances del desarrollo, dividiendo las actividades en tres columnas principales:

- *Por hacer*: tareas pendientes como creación de entidades y servicios.
- *En proceso*: tareas en desarrollo, como integración de vistas y controladores.
- *Completado*: tareas terminadas y verificadas.

En Trello creé tarjetas para cada módulo del proyecto.

Además, registré el avance en GitHub con un commit titulado:  
"creación tablero de gestión (Trello) y registro de tareas".
  
*Repositorio:* [store-web](https://github.com/Dariela1012/store-web)

Durante el desarrollo se utlizó la herramienta Jira
